двигателя; методы: движение, обслуживание, переключение передач, включение фар, включение дворников.
2. Создать конкретный автомобиль путём наследования класса «Car».
3. Расширить абстрактный класс «Car», добавить метод: подметать улицу. Создать конкретный автомобиль путём наследования класса «Car». Провести проверку принципа SRP.
4. Расширить абстрактный класс «Car», добавить метод: включение противотуманных фар, перевозка груза. Провести проверку принципа OCP.
5. Создать конкретный автомобиль путём наследования класса «Car», определить число колёс = 3. Провести проверку принципа LSP. 6. Создать конкретный автомобиль путём наследования класса «Car», определить метод «движение» - «полёт». Провести проверку принципа LSP.
7. Создать интерфейс «Заправочная станция», создать метод: заправка топливом.
8. Имплементировать метод интерфейса «Заправочная станция» в конкретный класс «Car».
9. Добавить в интерфейс «Заправочная станция» методы: протирка лобового стекла,
   протирка фар, протирка зеркал.
10. Имплементировать все методы интерфейса «Заправочная станция» в конкретный класс «Car». Провести проверку принципа ISP. Создать дополнительный/е интерфейсы и имплементировать их в конкретный класс «Car». Провести проверку принципа ISP.
11. Создать путём наследования класса «Car» два автомобиля: с бензиновым и дизельным двигателями, имплементировать метод «Заправка топливом» интерфейса «Заправочная
    станция». Реализовать заправку каждого автомобиля подходящим топливом. Провести проверку принципа DIP. 

___Summary___

1. Спроектировать абстрактный класс Car
   Задача: Создать абстрактный класс с необходимыми свойствами и методами.
   Реализация: Car.java содержит основные свойства (марка, модель, цвет, тип кузова и т.д.) и абстрактные методы, такие как движение, обслуживание, переключение передач, включение фар, включение дворников.
2. Создать конкретный автомобиль путем наследования класса Car
   Задача: Создать конкретные классы автомобилей, наследующиеся от Car.
   Реализация: Классы, такие как Sedan.java, Pickup.java, и другие, наследуются от Car и реализуют абстрактные методы.
3. Расширить абстрактный класс Car, добавить метод: подметать улицу. Проверка принципа SRP
   Задача: Добавить метод, связанный с подметанием улицы, и создать автомобиль для проверки принципа SRP.
   Реализация: Класс StreetSweeper.java наследуется от Car, добавляя метод подметать улицу.
   Проверка SRP: Проверка принципа единственной ответственности (SRP) заключается в том, что класс StreetSweeper отвечает за конкретную задачу - подметание улиц, что выделяет эту ответственность из общих задач автомобиля.
4. Расширить абстрактный класс Car, добавить методы: включение противотуманных фар, перевозка груза. Проверка принципа OCP
   Задача: Добавить новые функциональные возможности (противотуманные фары, перевозка груза) и проверить принцип OCP.
   Реализация: Эти новые функции добавлены в специализированные классы, например, Pickup.java для перевозки груза.
   Проверка OCP: Принцип открытости/закрытости (OCP) выполнен, поскольку новые функции добавляются через расширение класса, а не модификацию базового класса Car.
5. Создать автомобиль с числом колес = 3. Проверка принципа LSP
   Задача: Создать автомобиль с тремя колесами и проверить принцип LSP.
   Реализация: Класс ThreeWheeler.java реализует автомобиль с тремя колесами.
   Проверка LSP: Принцип подстановки Лисков (LSP) проверяется тем, что этот автомобиль можно использовать везде, где ожидается обычный автомобиль с четырьмя колесами, без нарушения логики программы.
6. Создать автомобиль с методом "движение" - "полёт". Проверка принципа LSP
   Задача: Создать автомобиль, который может летать, и проверить принцип LSP.
   Реализация: Класс FlyingCar.java реализует метод movement как "полёт".
   Проверка LSP: Принцип LSP проверяется тем, что этот класс можно использовать в коде, где ожидается обычное движение, без нарушения общих контрактов базового класса.
7. Создать интерфейс "Заправочная станция" с методом "Заправка топливом"
   Задача: Создать интерфейс для заправки топливом.
   Реализация: Интерфейс iRefueling.java содержит метод fuel() для заправки топливом.
8. Имплементировать метод интерфейса "Заправочная станция" в конкретный класс Car
   Задача: Реализовать интерфейс iRefueling в одном из классов автомобиля.
   Реализация: Классы, такие как SUV.java и DieselTruck.java, имплементируют интерфейс iRefueling и реализуют метод fuel().
9. Добавить в интерфейс "Заправочная станция" методы: протирка лобового стекла, протирка фар, протирка зеркал
   Задача: Добавить дополнительные методы для ухода за автомобилем.
   Реализация: Интерфейс iCleaning.java содержит методы для протирки лобового стекла, фар и зеркал.
10. Имплементировать все методы интерфейса "Заправочная станция" в конкретный класс Car. Проверка принципа ISP
    Задача: Реализовать интерфейс в одном из классов автомобиля и проверить принцип ISP.
    Реализация: Например, класс SUV.java имплементирует интерфейсы iRefueling и iCleaning.
    Проверка ISP: Принцип разделения интерфейсов (ISP) выполнен, так как классы автомобилей реализуют только те интерфейсы, которые им действительно нужны, без навязывания ненужных методов.
11. Создать два автомобиля: с бензиновым и дизельным двигателями, реализовать заправку подходящим топливом. Проверка принципа DIP
    Задача: Создать два типа автомобилей (с бензиновым и дизельным двигателями) и проверить принцип DIP.
    Реализация: Классы DieselTruck.java и GasolineCar.java реализуют интерфейс iRefueling, заправляя автомобили соответствующим топливом.
    Проверка DIP: Принцип инверсии зависимостей (DIP) соблюден, так как автомобили зависят от абстракции iRefueling, а не от конкретных реализаций заправки.
